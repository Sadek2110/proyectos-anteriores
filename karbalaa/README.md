# Karbalaa

Proyecto estatico servido con nginx para EasyPanel.

## Rutas publicas

- `/` - visualizacion HTML principal.
- `/visualizacion/` - misma visualizacion HTML.
- `/pdf/martirio-imam-husein-karbala.pdf` - PDF principal.
- `/presentacion/participantes-batalla-karbala.pdf` - presentacion en PDF.

## Estructura

- `public/visualizacion/` - pagina HTML.
- `public/pdf/` - documentos PDF.
- `public/presentacion/` - presentaciones exportadas.
- `public/img/` - imagenes usadas por la web.
